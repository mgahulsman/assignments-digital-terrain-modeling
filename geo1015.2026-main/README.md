# GEO1015.2026

For assignments and other files related to GEO1015.2026

If you use [uv](https://docs.astral.sh/uv/) (and in my opinion you should... it's great and fast) then:

1. `git clone https://gitlab.tudelft.nl/3d/geo1015.2026/`
2. `cd geo1015.2026`
3. `uv sync` (this installs all the necessary dependencies for the assignments)
4. `uv run geo1015_hw01.py` (runs the venv instead of another Python binary)
